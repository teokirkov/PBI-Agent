# Assignment briefs

Drop the assignment/brief document for a project here (e.g. the "BI Task"
PDF), or a subfolder per project if there end up being several:

```
docs/assignment/
  bi-task-1.pdf
  bi-task-1-notes.md      (optional: any clarifying context not in the PDF itself)
```

The agent reads this folder as step 1 of every project (`CLAUDE.md` §3,
"Discover"). If the brief is only accessible via SharePoint and not yet
committed here, see
`.claude/skills/sharepoint-data-ingestion/SKILL.md`.
