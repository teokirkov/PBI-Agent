# Projects

One folder per Power BI deliverable, created by the agent (or by hand) the
first time work starts on it:

```
projects/<project-name>/
  <ProjectName>.pbip
  <ProjectName>.Report/
  <ProjectName>.SemanticModel/
  NOTES.md         # run-to-run memory: what's done, what's open — required
  ANALYSIS.md       # written analysis/findings, if the assignment asks for one
```

See `CLAUDE.md` §0 and §2, and `.claude/skills/pbip-tmdl-structure/SKILL.md`
for the exact layout and conventions. This folder starts empty — nothing to
do here until the first project kicks off.
